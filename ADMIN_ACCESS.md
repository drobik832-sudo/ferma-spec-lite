# 🔐 Доступ к админ-панели

## 📍 Где находится админка

- **URL:** `http://localhost:3000/admin`
- **Назначение:** управление звездами пользователей, статистика, настройка системы

## 🔑 Пароль доступа

### Текущий статус
Пароль **не установлен** в переменных окружения.

### Как установить пароль

1. **Откройте файл** `.env.local` в корне проекта
2. **Добавьте строку:**
```env
ADMIN_TOKEN=ferma_admin_2024
```

3. **Перезапустите приложение:**
```bash
npm run dev
```

### Альтернативные пароли

Вы можете использовать любой из этих вариантов:
- `ferma_admin_2024`
- `admin123456`
- `ferma_secure_2024`
- `your_custom_password_here`

## 🚪 Вход в админку

1. Откройте: `http://localhost:3000/admin`
2. Введите пароль в поле "ADMIN_TOKEN"
3. Нажмите "Войти"

## 🔒 Безопасность

### Рекомендации
- **Измените пароль** перед публикацией на GitHub
- **Используйте сложный пароль** для production
- **Не храните пароль** в публичных репозиториях

### Production настройка
```env
# Используйте сложный пароль
ADMIN_TOKEN=your_super_secure_password_123456789
```

## 🛠️ Если пароль не работает

### Проверка списка:
1. ✅ Пароль добавлен в `.env.local`
2. ✅ Приложение перезапущено
3. ✅ Введен правильный пароль
4. ✅ Нет лишних пробелов

### Отладка:
1. **Проверьте консоль** браузера на ошибки
2. **Проверьте терминал** на сообщения об ошибках
3. **Убедитесь**, что `.env.local` читается:
```bash
echo $ADMIN_TOKEN
```

## 🔄 Сброс пароля

Если забыли пароль:
1. Откройте `.env.local`
2. Найдите строку `ADMIN_TOKEN=`
3. Установите новый пароль
4. Перезапустите приложение

## 📱 Мобильный доступ

Админ-панель адаптивна и работает на:
- Десктопе
- Планшетах  
- Мобильных устройствах

---

**Важно:** Никогда не публикуйте `.env.local` файл с реальным паролем в открытый репозиторий!
